# Simple Interest Calculator

A simple calculator script to compute simple interest based on principal, annual rate of interest, and time period. 

## Description
This project is part of the "Introduction to Git and GitHub" course. It demonstrates basic Git workflows, including branching, merging, and open-source contribution practices.

## Formula
Simple interest is calculated using the following formula:
`I = P * R * T`
* **I** = Simple Interest
* **P** = Principal amount
* **R** = Annual interest rate
* **T** = Time period (in years)

To use the calculator, run the bash script in your terminal:
